Part 1 · 2 min

Why More Layers Can Hurt

Understanding why added layers can worsen training explains why the paper changes how deep networks learn, rather than simply making them larger.

Kaiming He, Xiangyu Zhang, Shaoqing Ren, and Jian Sun of Microsoft Research present residual learning, a way to express what network layers learn so that substantially deeper neural networks become easier to train. Their starting question is whether stacking more layers is enough to produce better networks.

Depth means the number of stacked layers. Deep networks combine low-, middle-, and high-level image features, the information used to recognize images. More layers can enrich these levels of features. However, the potential to represent richer information does not guarantee better accuracy after training.

Gradients are signals that guide changes to a network during training. Vanishing gradients become too small; exploding gradients become too large. Training error measures mistakes on examples used for learning; test error measures mistakes on separate examples. Overfitting means learning the training examples without doing equally well on separate examples.

Vanishing or exploding gradients can prevent training from progressing successfully from the start. Normalized initialization, which sets starting weights, and intermediate normalization layers, which adjust signals within the network, had largely addressed this obstacle. Networks with tens of layers could therefore begin learning, but another difficulty remained.

Figure note: Figure 1

On CIFAR-10, an image dataset, the left plot shows training error and the right shows test error. The 56-layer plain network, which simply stacks layers, has higher error than the 20-layer network in both plots. This illustrates degradation: as depth increases, accuracy stops improving and then worsens.

Common mistake

Do not explain this result merely as overfitting. The deeper model performs worse even on its training examples. The central problem is optimization: the training procedure struggles to find a good solution, not merely to perform well on unseen images.

Why a deeper solution should exist

  1. Start with a trained shallower network.
  2. Copy its learned layers into a deeper network.
  3. Make the added layers pass their inputs through unchanged, an identity mapping.
  4. This constructed deeper network should have no higher training error. Yet actual training may fail to find an equally good solution in feasible time.

Key idea

A good solution can exist without being easy to learn. This gap motivates expressing the network's functions differently. Simply training longer is not a sufficient practical answer: the authors still observed degradation with 3 × more training iterations.

In short

  • Greater depth can enrich image features, but does not automatically improve accuracy.
  • Degradation is a training difficulty distinct from vanishing gradients and overfitting.
  • The existence of a good deeper solution motivates changing how the learning problem is expressed.

Check yourself

Part 2 · 2 min

Learn Changes Instead of Whole Mappings

Residual learning changes what layers must learn, aiming to make training easier without claiming greater power to represent functions.

ℱ(𝐱) := ℋ(𝐱) − 𝐱, so ℋ(𝐱) = ℱ(𝐱) + 𝐱
𝐱The input to a block, meaning a few stacked layers, not necessarily the whole network.
ℋ(𝐱)The desired mapping: the output those layers should produce for input 𝐱.
ℱ(𝐱)The residual mapping: the correction relative to the input that the stacked layers learn.

Key idea

Learn the correction, then add back the input. The central hypothesis concerns optimization, meaning how easily training finds suitable weights. Under the paper’s approximation hypothesis, both formulations can approach the desired functions. The claim is not that residual learning represents more functions, but that learning ℱ may be easier than learning ℋ directly.

Consider the concrete case where the best output is the input unchanged. This is an identity mapping: ℋ(𝐱) = 𝐱. The required residual is therefore zero.

Instead of making stacked nonlinear layers reproduce their input, training can drive their weights toward zero. Their residual output then approaches zero, so adding the input approaches the desired unchanged output.

An unchanged input is unlikely to be optimal in real cases. Still, if the desired mapping is closer to identity than to zero, learning a small change around identity may be easier than learning the entire mapping afresh. The paper reports that learned residual functions generally have small responses, supporting identity as a useful starting reference.

Residual ideas have precedents. VLAD represents images using differences from a dictionary; Fisher Vector has a probabilistic formulation related to VLAD. Residual vector encoding represents differences rather than original vectors.

Multigrid and hierarchical basis methods solve mathematical systems using residual differences between scales. These methods converge faster than standard solvers unaware of those residuals, motivating the broader idea that reformulating a problem can simplify optimization.

Figure note: Figure 2

The residual building block combines two paths: stacked layers learn ℱ(𝐱), while a shortcut connection skips layers and carries 𝐱 unchanged. Adding their outputs implements ℱ(𝐱) + 𝐱.

Shortcut connections predate this work. Highway networks use learned, data-dependent gates that can close their shortcuts. Here, identity shortcuts have no learned parameters and never close: the input always passes through, while the layers learn an additional residual.

In short

  • Residual learning rewrites the desired output as input plus a learned correction.
  • If identity is optimal, the correction should be zero.
  • The proposed advantage is easier optimization, not greater representational power.

Check yourself

If passing the input through unchanged is optimal, what should ℱ(𝐱) be?

The residual is ℋ(𝐱) − 𝐱. When ℋ(𝐱) = 𝐱, that difference is zero.

Answer: Zero

How do the paper’s identity shortcuts differ from highway-network shortcuts?

Highway networks have parameterized, data-dependent gates; the paper’s identity shortcuts always pass the input through.

Answer: They have no parameters and are never closed.

Part 3 · 2 min

Blocks, Shortcuts, and Network Structure

Residual networks add shortcut paths to ordinary stacks of layers, changing how blocks compute without necessarily adding learned parameters.

𝐲 = ℱ(𝐱, {Wᵢ}) + 𝐱 ℱ = W₂σ(W₁𝐱)
𝐱The block’s input.
𝐲The sum of the learned branch’s output and the shortcut input, before the following activation.
WᵢThe learned weights of the layers in the residual branch.
ℱThe residual function; the second equation shows the two-layer example, with biases omitted.
σReLU, the activation used between the two layers. Another ReLU follows the addition: σ(𝐲).

Figure note: Figure 2

The building block has two paths: stacked layers compute ℱ, while a shortcut skips those layers and carries 𝐱 directly to the addition. Corresponding entries are added, not joined into a longer output.

A shortcut can skip one or more layers. An identity shortcut passes its input through unchanged, adds no learned parameters, and costs only negligible entry-by-entry addition. This permits fair plain/residual comparisons with the same depth, width, parameter count, and computational cost.

Residual functions can contain two or three layers, including convolutional layers. For convolutional outputs, addition operates channel by channel. The authors observed no advantage from a residual function containing only one layer.

Addition requires matching input and output dimensions. When dimensions increase, option A keeps the identity shortcut and pads it with zeros, adding no parameters. Option B learns a projection Wₛ through a 1 × 1 convolution, giving 𝐲 = ℱ(𝐱, {Wᵢ}) + Wₛ𝐱.

For either option, shortcuts crossing different spatial feature-map sizes use stride 2. Projections are otherwise unnecessary when dimensions already match.

The 34-layer plain baseline mostly uses 3 × 3 filters. Filter counts stay constant within each spatial output size and double when that size halves. Stride-2 convolutions perform downsampling, reducing spatial size. Global average pooling precedes a 1000-way fully connected classification layer with softmax.

Figure note: Figure 3

Compare VGG-19 on the left with the 34-layer plain network in the middle and its residual counterpart on the right. Both 34-layer models require 3.6 billion FLOPs, the paper’s multiply-add count, versus 19.6 billion for VGG-19. Solid shortcuts preserve dimensions; dotted shortcuts increase them.

Figure note: Table 1

The table specifies residual architectures with 18, 34, 50, 101, and 152 layers. Brackets describe building blocks; multipliers state how many are stacked. Downsampling occurs at conv3_1, conv4_1, and conv5_1, each using stride 2.

In short

  • A residual block adds its learned branch to a shortcut, then applies another activation.
  • Identity shortcuts add no learned parameters; dimension increases use zero padding or a learned projection.
  • The 34-layer residual architecture retains the plain baseline’s reported 3.6 billion FLOPs.

Check yourself

Part 4 · 2 min

Training and Testing the Models

A shared ImageNet training procedure makes the plain and residual network comparisons meaningful, while testing choices determine which reported errors can be compared.

The experiments use ImageNet 2012, an image-classification dataset with 1000 classes, or categories. Networks learn from 1.28 million training images and are evaluated on 50k validation images. A final evaluation uses 100k test images, with results reported by the test server.

Prepare each training image

  1. Resize the image so its shorter side is randomly chosen within [256,480]. This provides scale augmentation: training with different image sizes.
  2. Randomly select a 224 × 224 crop from the image or its horizontal flip, a left-to-right reversal.
  3. Subtract the per-pixel mean, the average value at each pixel position.
  4. Apply the standard color augmentation cited in [21], which varies image colors.

Batch normalization follows every convolution and comes before activation. Both plain and residual networks are trained from scratch, rather than starting with previously learned weights. Their weights are initialized using the method cited in [13]. These choices apply to both network families.

For comparison experiments, the authors use standard 10-crop testing: evaluating ten crops rather than just one. For their best results, they instead use the fully convolutional form cited in [41,13] and average prediction scores across image scales. The shorter-side sizes are {224,256,384,480,640}. These are different testing procedures, not interchangeable labels for the same evaluation.

Top-1 error counts images whose highest-ranked prediction is wrong. Top-5 error counts images whose correct class is absent from the five highest-ranked predictions. An ensemble combines multiple models, unlike a single-model result.

Key idea

Before comparing reported errors, check the metric, the dataset split, the testing procedure, and whether the result uses one model or an ensemble. The paper separately reports validation results, test-server results, single-model results, and ensemble results.

In short

  • Plain and residual networks are trained from scratch under shared ImageNet settings.
  • Comparison studies use 10-crop testing; best results use fully convolutional, multi-scale evaluation.
  • Compare numbers only after checking the error metric, data split, testing procedure, and model count.

Evidence That Residual Learning Helps

Controlled comparisons show that shortcuts make training easier and turn added depth from a disadvantage into an accuracy gain.

Figure note: Table 2

This table reports ImageNet validation top-1 error, the percentage of images whose highest-ranked prediction is wrong, using 10-crop testing. Lower is better. Plain-network error rises from 27.94% at 18 layers to 28.54% at 34 layers. With residual learning, it falls from 27.88% to 25.03%.

These ResNets use option A: shortcuts pass inputs through unchanged, adding zeros where dimensions increase. They introduce no extra learned parameters, so extra parameters cannot explain the improvement.

Figure note: Figure 4

Thin curves show training error; bold curves show validation error using center crops, not Table 2's 10-crop testing. The left panel compares plain networks; the right compares ResNets.

Plain-34 has higher training error than plain-18 throughout training. ResNet-34 has much lower training error than plain-34, and its improvement carries over to validation images. At 18 layers, final accuracy is similar, but the ResNet converges faster: it approaches a good solution sooner during early training.

Why does plain-34 struggle? The authors argue that vanishing gradients, learning signals becoming too small as they travel backward, are unlikely to explain it. Batch normalization keeps forward signals' variance, their amount of variation, nonzero. Measured backward-gradient norms, measures of those signals' size, are also healthy.

Training for three times as many iterations still leaves degradation. The authors suggest very slow convergence as a possibility, but the precise cause of the optimization difficulty remains unresolved.

Figure note: Table 3

For ResNet-34, 10-crop top-1 errors are 25.03% for A, 24.52% for B, and 24.19% for C. A has parameter-free shortcuts; B uses learned projections only when dimensions increase; C uses projections on every shortcut. All three outperform plain-34 at 28.54%. Thus, learned shortcut projections are not essential for overcoming degradation in this comparison.

The authors attribute B's small advantage over A to A's zero-padded dimensions having no residual learning. They attribute C's small further advantage to extra parameters from thirteen projection shortcuts. They drop C from the remaining experiments to reduce memory use, computation time, and model size.

Key idea

The strongest evidence is reduced training error without extra parameters: shortcuts ease optimization, allowing greater depth to improve validation accuracy.

In short

  • Increasing depth hurts the plain networks but helps the parameter-free ResNets.
  • At 18 layers, residual learning improves early training speed rather than final accuracy.
  • Projection shortcuts offer small additional gains, but they are not necessary.

Efficient Depth and Reported Achievements

Bottleneck blocks make much deeper residual networks economical, allowing increased depth to deliver stronger recognition results.

A bottleneck residual branch uses three convolutions, layers that apply learned filters: 1 × 1 reduces dimensions, meaning the number of feature channels; 3 × 3 processes this smaller representation; and 1 × 1 restores dimensions. The design mainly keeps deeper networks economical in training time and computation, rather than being essential for accuracy gains from depth.

Figure note: Figure 5

The left block belongs to ResNet-34 and operates on 56 × 56 feature maps. The right is the bottleneck used by ResNet-50/101/152. Both designs have similar computational cost. An identity shortcut passes its input through unchanged. Replacing the illustrated bottleneck's identity shortcut with a learned projection doubles that block's computational cost and model size because the projection connects its two high-dimensional ends.

Figure note: Table 1

Replacing every two-layer block of ResNet-34 with a three-layer bottleneck produces ResNet-50. Option B uses projections only when dimensions increase, otherwise retaining identity shortcuts. Table 1 also specifies 101- and 152-layer models: brackets identify blocks, and multipliers give repetition counts. Downsampling, reducing spatial size, occurs at conv3_1, conv4_1, and conv5_1 with stride 2. ResNet-152 needs 11.3 billion FLOPs, the paper's computation count in multiply-adds, below VGG-19's 19.6 billion.

Figure note: Table 3

With 10-crop testing, ImageNet validation top-1/top-5 errors are ResNet-50: 22.85%/6.71%; ResNet-101: 21.75%/6.05%; ResNet-152: 21.43%/5.71%. These measure failure to place the correct class first or among the five highest-ranked predictions. Lower is better: both errors decrease as depth increases.

Figure note: Table 4

The best reported single-model ResNet-152 validation errors are 19.38% top-1 and 4.49% top-5. Keep these separate from Table 3's 10-crop results. Table 4 reports validation results except the entry marked †, which uses test data.

Figure note: Table 5

An ensemble combines multiple models. The residual ensemble achieves 3.57% top-5 test error, reported by ImageNet's test server, and wins the ILSVRC 2015 classification task. This is not a single-model validation result.

The abstract also reports CIFAR-10 analysis with 100 and 1000 layers, a 28% relative improvement on COCO object detection, and first places in ImageNet detection and localization and COCO detection and segmentation.

The supplied excerpt ends during the ResNet-50 description. It therefore does not provide the later experimental details behind these broader claims.

In short

  • Bottlenecks reduce, process, and restore dimensions to make depth economical.
  • Identity shortcuts avoid expensive projections between high-dimensional ends.
  • Distinguish 10-crop validation results, best single-model results, and ensemble test results.

Glossary

Plain network
A network that simply stacks layers without the residual shortcut connections studied here.
Degradation problem
The worsening of training accuracy as network depth increases, even though a deeper model could in principle reproduce a shallower model's solution.
Residual mapping
The change a block learns relative to its input: ℱ(𝐱) := ℋ(𝐱) − 𝐱. Adding the input back gives the desired mapping.
Identity mapping
A mapping that passes its input through unchanged. In a residual block, a zero residual leaves this unchanged-input path.
Shortcut connection
A connection that skips one or more layers. Here its output is added to the output of the learned residual branch.
Projection shortcut
A shortcut that applies a learned linear mapping Wₛ to its input, allowing dimensions to match before addition.
Bottleneck block
A three-layer residual branch with 1 × 1, 3 × 3, and 1 × 1 convolutions. The first and last layers reduce and restore dimensions so the middle layer works with fewer dimensions.
FLOPs
The paper's measure of computational work, reported as multiply-adds. It uses this measure to compare network complexity.
ReLU
An activation function that keeps positive inputs and sets negative inputs to zero. The paper denotes it by σ. Added background
Batch normalization
A method that normalizes intermediate network signals during training. This paper places it immediately after each convolution and before activation. Added background
Stochastic gradient descent
A training method that updates learned weights using gradients estimated from batches of examples. The paper abbreviates it as SGD. Added background
Top-1 and top-5 error
Top-1 error counts images whose highest-ranked predicted class is wrong. Top-5 error counts images whose correct class is absent from the five highest-ranked predictions. Added background
Ensemble
A combination of multiple models' predictions rather than a single model's prediction. Added background
